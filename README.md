# 🕉 Sanātana Dharma Guide (सनातन धर्म - beginner's path)

> **A free, structured, fact-checked learning portal for absolute beginners seeking to understand the roots, scriptures, philosophy, and lifestyle of Sanātana Dharma.**

---

## ✨ Key Features

- 📖 **Backed by 20 Primary Original Books** (18,982 pages analyzed): Rig Veda, 108 Upanishads, Bhagavad Gita, Valmiki Ramayana, Mahabharata (10 Volumes), Bhagavata Purana, Shiva Purana, Brahma Sutras, Samkhya & Vaisheshika Sutras.
- 🎯 **100% Fact-Checked & Zero Propaganda**: Every lesson includes real Sanskrit shlokas, IAST transliterations, English translations, and direct source book page citations.
- 📚 **In-Browser Library Viewer**: Direct PDF reader embedded in `library.html` letting users read and verify every original text for themselves.
- 📱 **Mobile-First Responsive Design**: Full hamburger navigation, responsive cards, and clean typography.
- 🎬 **Cinematic Animated Entrance Page**: Particle starfield, glowing OM symbol, and sacred mandala geometry.
- ⚡ **Zero External Heavy Dependencies**: Pure Vanilla HTML5, CSS3, JavaScript. Super fast load times.

## 🚀 How to Host on GitHub Pages (Free Web Hosting)

1. **Push this repository to GitHub** (see instructions below).
2. Go to your repository on GitHub: **Settings → Pages**.
3. Under **Build and deployment → Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live in 60 seconds at `https://<your-username>.github.io/<repository-name>/landing.html`!

---

## 💻 Git Commands to Push to GitHub

```bash
# 1. Initialize git repository
git init

# 2. Add all files
git add .

# 3. Commit files
git commit -m "Initial commit: Complete Sanatan Dharma Guide website with 9 modules, 17 lessons, and source library"

# 4. Set main branch
git branch -M main

# 5. Add remote GitHub URL (replace with your repo URL)
git remote add origin https://github.com/YOUR_USERNAME/sanatan-dharma-guide.git

# 6. Push to GitHub
git push -u origin main
```
