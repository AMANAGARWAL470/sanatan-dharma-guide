# Project Storage Rules

1. All code, subpages, styling, scripts, and website files MUST reside in `D:\Sanatan Dharam project\`.
2. All project dumps, temporary scripts, extraction JSONs, and cache MUST reside in `D:\Sanatan Dharam project\Dumps\`.
3. All dependencies, external Android tools, npm/pip caches MUST reside in `D:\`.
